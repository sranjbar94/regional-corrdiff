# Figure Scripts

Generates all paper figures from pre-computed evaluation NetCDF files.

## Quick start
```bash
sbatch run_all_figures.sh
```

## Slow standalone figures
```bash
sbatch run_figure_S5.sh      # Fig S5: CRPS vs ensemble size (~8 min)
sbatch run_figure_S9_v5.sh   # Fig S9: Training data coverage
```
