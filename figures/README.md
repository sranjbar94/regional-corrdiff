# Figure Generation Scripts

All figures in the paper are generated from the scripts in this directory. The main pipeline script (`run_all_figures.sh`) runs the fast figures in one ~10-minute job. Two supplementary figures (S5 and S9) are computationally heavier and have dedicated sbatch scripts.

## Dependencies

```bash
pip install matplotlib numpy scipy netCDF4 geopandas geodatasets
```

All scripts import shared style utilities from `scripts/fig_style.py`.

## Quick Start

```bash
# Edit paths in run_all_figures.sh to point to your eval NetCDF files, then:
sbatch run_all_figures.sh
```

## Slow Standalone Figures

Fig S5 reads raw 16-member ensemble chunk files and takes ~8 minutes. Run separately:
```bash
sbatch run_figure_S5.sh
# Re-plot from cached results only (fast):
python3 scripts/figure_S5_ensemble_sensitivity.py --from-cache output/figure_S5_cache.json --outdir output
```

Fig S9 reads the full 100,000-sample training NetCDF:
```bash
sbatch run_figure_S9_v5.sh
```

## Eval Data Requirements

The figure scripts expect pre-computed evaluation NetCDF files generated by the scoring scripts (`score_g{1,2,3}.py`). These files are produced by running inference on the V5 test set and then merging the chunk outputs.
